# Great Scale CXLXI — Canonical Quotient Repair

## Descent question
After a model change, how can we know whether the cached quotient is merely safe or is still the coarsest quotient required by the current model?

## Current-model equivalence
Initialize the partition by joint observation and required-property signatures. Repeatedly split states by their current observation and property vector, enabled action set, and successor partition block for each action (including terminal behavior).

At a fixed point, states in a block agree on these signatures. This implementation computes the partition from the current model rather than trusting old distinctions.

## Repair audit
Given cached partition Pi_old and recomputed canonical partition Pi_star, report whether Pi_old is exactly Pi_star. A mismatch is a repair signal. Partition mismatch does not alone imply the cache violates safety; it may only be over-refined.

## Key mathematical result
For finite deterministic systems, refinement terminates because each strict iteration splits at least one block, and there are at most |S| blocks. The stable partition is the coarsest partition generated by this signature-refinement procedure, assuming well-formed model mappings and action labels.

## Profound finding
**A cache needs a certificate, not just a history.** The old partition's origin does not prove it is still canonical after an update. A repair audit must check the present model; exact canonicality and behavioral safety are different predicates.

## Limitations
Finite deterministic transitions and Python hashable state/action labels only. Action ordering uses repr as a comparison key; distinct labels with colliding representations should be normalized. Tests are authored, not claimed passed until CI reports completion.

## Great Scale ladder
CXLVII property preservation → CXLVIII property-guided refinement → CXLIX joint fixed point → CXLX robustness under model change → **CXLXI canonical quotient repair**.

This is a formal result about the stated model class, not empirical proof about physical systems.
